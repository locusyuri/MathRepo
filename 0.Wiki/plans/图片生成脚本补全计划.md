## 5. 迁移规范（技术决策）

1. **脚本命名**：与图片同名，kebab-case（`cosets-partition.svg` → `scripts/cosets-partition.py`）。现有仓库脚本已是该风格（少数下划线例外如 `mobius_strip.py`，不追溯改名）。
2. **`_viz` 依赖处理**：把 `physics-viz/src/_viz/output.py` 复制为**每条笔记**的 `scripts/_viz.py`（单文件，保留 `OutputSpec` / `Presets`），脚本只需改两处：
   - `sys.path.insert(0, str(Path(__file__).resolve().parent))` + `from _viz import Presets`；
   - 去掉指向 physics-viz `src/` 的 path 依赖；
   理由：不引入跨目录包依赖，保持「一条笔记自包含」，与现有脚本风格一致。
3. **输出路径**：`OUT_DIR = Path(__file__).resolve().parent.parent / "img"`，`SPEC.save(fig, OUT_DIR / "<图片名>")`；不依赖外部 `output/` 目录，也不依赖运行时 cwd。
4. **重复脚本**：`carnot_cycle.py`、`maxwell_speed_distribution.py` 以仓库内版本为唯一权威，physics-viz 版本仅作对照，不迁入；`carnot-cycle.svg` 内容差异按仓库版本重新出图后覆盖。
5. **格式**：`math_paper` 系统一 SVG（`transparent=False` 视图形而定，保持与现有图片观感一致）；`electric_field`/`magnetic_field` 保持 PNG 300 dpi。
6. **文档风格**：文件头保留英文 docstring（图形内容 + 输出路径），与 physics-viz 原脚本一致；改动说明用中文注释（遵循仓库约定）。
