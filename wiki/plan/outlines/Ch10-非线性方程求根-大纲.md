## 零、章节定位与核心洞察

**章节定位**：Part IV 的开篇。前三部分处理「函数/矩阵层面的近似与计算」，本章转向「方程求解」：给定 $f$，找 $x^*$ 使 $f(x^*)=0$。它把 §2.4 的收敛阶语言第一次系统用于迭代算法，并为 Ch11 的隐式 ODE 格式与 Ch12 的打靶法提供内层 Newton 求解器。

**核心洞察**：**所有求根方法都是把 $f$ 换成一个可迭代的映射，收敛阶由该映射在根处的 Taylor 首项决定**。二分法只用区间与符号（全局但线性），Newton 用导数（局部但二阶），弦截法/Müller 用插值替代导数（超线性、无需导数），Broyden 把这一替代搬到方程组。方法的选择本质上是「信息类型」与「收敛阶」的交换。

**组织主线**：从「只需符号」的二分法（最稳健、最慢）出发，逐步加入信息——函数值（不动点）→ 导数（Newton）→ 历史点上的函数值（弦截/Müller）→ Jacobian（方程组）。每加一种信息，收敛阶提高，但全局稳健性下降；§10.5 把这条交换关系定量化。

**节序决策**：保持蓝图顺序。§10.2 虽以不动点迭代命名，实际重心是「如何构造 $\phi$」与「如何加速」，与数学分析的纯理论小节互补而不重复。

### §10.1 Bisection Method // 二分法

| 内容 | 组件/标签 | 备注 |
|---|---|---|
| 二分算法：$m_k=(a_k+b_k)/2$，保留变号子区间 | `#definition` `<def:bisection-method>` + `eq:bisection-update` | 回链 `thm:intermediate-value`（存在性）；只要求 $f$ 连续 |
| 停机准则：区间宽度、增量、相对增量、$abs(f(x_k))$ | `#definition` `<def:stopping-criterion>` | 全章共用；§10.3/§10.5 回指 |
| $abs(f(x_k))<epsilon$ 不蕴含 $abs(x_k-x^*)<epsilon$ | `#caution`（无标签） | 误差比 $abs(f)/abs(f')$；回链 §2.4 的有限精度警告 |
| 收敛性：误差 $<=(b-a)\/2^(k+1)$，线性收敛率 $1\/2$ | `#theorem` `<thm:bisection-convergence>` + `eq:bisection-error` | 证明：归纳区间长度；不需可微性 |

| 算例：$x^3-2=0$ 于 $[1,2]$ | `#example` `<ex:bisection-cube-root>` | 10 步约 3 位、20 步约 6 位，直观展示每步只赚约 0.3 位 |
| 二分法的边界：偶重根、无括号区间、速度慢 | `#note`（无标签） | 不能用于无变号情形；引出后续方法 |

### §10.2 Fixed-Point Iteration and Acceleration // 不动点迭代与加速

| 内容 | 组件/标签 | 备注 |
|---|---|---|
| 把 $f(x)=0$ 改写为 $x=phi(x)$；不同 $\phi$ 给出不同迭代 | 普通 prose + `eq:fixed-point-iteration` | Newton 是 $phi=x-f\/f'$ 的特例；不新设「不动点」定义 |
| 压缩定理与导数判据的复述 | `#note(title: "The contraction theorem, recalled")` | 引用 *Analyse Mathématique* 的 *Iterative Sequences*：唯一不动点、收敛、$abs(phi'(x^*))<1$、后验界；**不重证** |
| 收敛阶由 $\phi$ 在 $x^*$ 处的 Taylor 首项决定 | `#proposition` `<prop:fixed-point-order>` + `eq:fixed-point-order` | 证明：`thm:taylor-lagrange`；$phi'(x^*)!=0$ 时线性率 $abs(phi'(x^*))$ |
| Aitken $\Delta^2$ 加速 | `#proposition` `<prop:aitken-acceleration>` + `eq:aitken` | 证明：设 $x_k=x^*+C lambda^k$ 代入；误差平方化 |
| Steffensen 迭代：以差商替代 $\lambda$ | 普通 prose + `eq:steffensen` | 公式 $x_(k+1)=x_k-(phi(x_k)-x_k)^2\/(phi(phi(x_k))-2phi(x_k)+x_k)$；方法本身不另设定义 |
| Steffensen 的二次收敛 | `#theorem` `<thm:steffensen-convergence>` | 证明：其迭代函数 $G$ 满足 $G'(x^*)=0$，再用 `prop:fixed-point-order` |
| 加速的风险 | `#caution`（无标签） | $lambda approx 1$ 或分母近零时不稳定；非全局方法 |
| 算例：$phi(x)=(x+2)\/(x+1)$，根为 $sqrt(2)$ | `#example` `<ex:fixed-point-acceleration>` | 线性率约 $1\/(1+sqrt(2))^2 approx 0.1716$；展示 Aitken/Steffensen 的位数提升 |
| 蛛网图不必重画 | 普通 prose | 回指 *Iterative Sequences* 的 `fig:iteration-cobweb` |

### §10.3 Newton's Method // Newton 法

| 内容 | 组件/标签 | 备注 |
|---|---|---|
| 切线/线性化推导与迭代公式 | `#definition` `<def:newton-method>` + `eq:newton-update` | $x_(k+1)=x_k-f(x_k)\/f'(x_k)$；需 $f'(x_k)!=0$ |
| 作为不动点迭代：$phi=x-f\/f'$，$phi'(x^*)=0$ | 普通 prose | 与 §10.2 的 `prop:fixed-point-order` 直接衔接 |
| 根的重数 | `#definition` `<def:root-multiplicity>` | $f^((j))(x^*)=0$（$j<m$），$f^((m))(x^*)!=0$；数学分析笔记未定义，故在此补 |
| 局部二次收敛 | `#theorem` `<thm:newton-convergence>` + `eq:newton-error` | 证明：`thm:taylor-lagrange` 一阶展开；$e_(k+1)=(f''(xi)\/(2f'(x_k)))e_k^2$ |
| 重根时退化为线性 | `#proposition` `<prop:newton-multiple-root>` + `eq:modified-newton` | 率 $1-1\/m$；修正 Newton $x_(k+1)=x_k-m f\/f'$ 恢复二阶 |
| 阻尼 Newton 与线搜索 | `#note(title: "Damped Newton and line search")` | $x_(k+1)=x_k-alpha_k f\/f'$，回溯选 $alpha_k$；只讲策略不证全局收敛 |
| 算例：$x^3-2=0$ | `#example` `<ex:newton-cube-root>` | 从 $x_0=1.5$ 出发，误差约 $2.4 times 10^(-1), 3.6 times 10^(-2), 1.1 times 10^(-3), 10^(-8)$ |
| 反例：$x^3-2x+2=0$，$x_0=0$ 陷入 $0<->1$ 循环 | `#example` `<ex:newton-cycle>` | 说明局部性；需要括号或阻尼 |
| 与优化 Newton 的区别 | 并入 `#note(title: "Damped Newton and line search")` | 求根 Newton 解 $f=0$；最优化 Newton 解 $nabla g=0$ 并用 Hessian，见 `Optimisation Convexe` |

| 内容 | 组件/标签 | 备注 |
|---|---|---|
| 弦截法：用差商替代导数 | `#definition` `<def:secant-method>` + `eq:secant-update` | 回链 Ch3 `def:divided-difference`；需两个初值 |
| 局部超线性收敛，阶 $(1+sqrt(5))\/2 approx 1.618$ | `#theorem` `<thm:secant-convergence>` | 证明：误差递推 $e_(k+1) approx C e_k e_(k-1)$ + 指数平衡 $p^2=p+1$ |

### §10.6 Systems of Nonlinear Equations // 非线性方程组

| 内容 | 组件/标签 | 备注 |
|---|---|---|
| 多元 Newton：解 $J_F(x^((k))) s_k=-F(x^((k)))$，$x^((k+1))=x^((k))+s_k$ | `#definition` `<def:newton-system>` + `eq:newton-system` | 回链 `def:jacobian-matrix-mapping`；线性系统用 Ch7 |

| `<prop:aitken-acceleration>` | 设 $x_k=x^*+C lambda^k+O(mu^k)$，直接代入 $\Delta^2$ 公式 | 代数化简 |
| `<thm:steffensen-convergence>` | 写出迭代函数 $G$，验证 $G'(x^*)=0$，再用 `prop:fixed-point-order` | Taylor、`prop:fixed-point-order` |
| `<thm:newton-convergence>` | 一阶 Taylor 得 $e_(k+1)=(f''(xi)\/(2f'(x_k)))e_k^2$；用 $f'$ 连续性与 $f'(x^*)!=0$ 控制分母 | `thm:taylor-lagrange` |
| `<prop:newton-multiple-root>` | 写 $f=(x-x^*)^m g$，$g(x^*)!=0$；展开 $f\/f'$ 得 $phi'(x^*)=1-1\/m$ | 代数展开 |
| `<thm:secant-convergence>` | 误差递推 $e_(k+1) approx C e_k e_(k-1)$；设 $e_(k+1)=A e_k^p$ 解 $p^2=p+1$ | 插值误差、指数平衡 |
| `<thm:newton-system-convergence>` | 多元 Taylor：$F(x_k)=J(x_k)e_k+O(||e_k||^2)$；$J$ 在 $x^*$ 附近可逆且有界 | `def:jacobian-matrix-mapping`、`def:matrix-norm` |
| Müller 阶、Broyden 超线性 | 陈述标准结果，不证（放在 `#note`） | — |
