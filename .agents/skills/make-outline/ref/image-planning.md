# 图片规划与提示词编写指南

本文件指导在大纲规划阶段如何判断图片必要性，以及如何编写面向 Python/Matplotlib 脚本生成的详细绘图提示词。

---

## 1. 图片必要性判断

### 1.1 核心原则：图片必须传递文字无法高效传递的信息

数学笔记中的图片不是装饰，而是**证明或理解的必要辅助**。判断标准：

> **如果去掉这张图，读者是否需要花更多时间从文字/公式中重建几何直觉？如果是，图有必要；如果文字已经足够清晰，图就是凑数。**

### 1.2 三级判断

| 级别 | 判断 | 标准 | 处理 |
|------|------|------|------|
| **A. 必须有** | 几何构造是证明/概念的核心 | 去掉图后读者无法理解论证 | 规划并编写详细提示词 |
| **B. 建议有** | 图能显著加速理解，但文字也能说清 | 多概念对比、复杂域映射 | 规划但可降级为简版 |
| **C. 不需要** | 公式本身已自明，或图只是文字的重述 | 简单函数图、单一定义的示意 | **不画图** |

### 1.3 具体判断清单

**A 级（必须有图）**：
- 证明中用到的几何构造（如围道变形、圆环内的积分路径）
- 复平面上的域映射（z-平面 → w-平面，因为映射后的形状无法从公式直觉得到）
- 多值函数的分支结构（branch cut、Riemann 曲面）
- 需要视觉对比的多个对象（如三类奇点的 Laurent 展开对比）
- 收敛区域的几何刻画（如收敛半径 = 到最近奇点的距离）

**B 级（建议有图）**：
- 函数模长的曲面/等高线（如 |sin z| 的周期结构）
- 映射前后的网格变形（保角映射的直观）
- 多个相关概念的并排对比（如三种收敛行为）

**C 级（不画图）**：
- 简单定义的文字叙述已经足够（如"开圆盘"的定义 — 读者知道圆盘长什么样）
- 公式本身已经自明的函数图像（如 $e^x$ 的曲线 — 不需要图来理解指数增长）
- 仅标注一个点或一条线的"示意图"（信息量太低）
- 纯代数推导中无几何含义的中间步骤
- 与前后章节已有图片高度重复的内容

### 1.4 数量控制

- 每章 **1-3 张图** 是正常范围
- 超过 4 张需要审视：是否有 C 级图可以删除？
- 一节内最多 1 张图；如果某节需要 2 张以上，考虑合并为多面板

## 2. 提示词编写规范

### 2.1 工作流

图片提示词的消费方是**另一个 AI**，该 AI 读取提示词后编写 Python/Matplotlib 脚本生成 SVG。因此提示词必须：

1. **数学精确**：所有坐标、公式、几何关系必须可计算
2. **视觉完整**：每个可见元素都要描述（颜色、线型、位置）
3. **结构清晰**：按固定格式组织，便于 AI 解析

### 2.2 提示词结构模板

每张图的提示词以**自然语言段落**形式编写，**禁止使用表格**（markdown 表格语法 `| ... | ... |`）。整体结构为：开头一行标题（文件名 + 标签），随后是若干以方括号小节标题领起的段落，依次覆盖整体描述、各面板/层次、配色与文字说明、数学验证。

基础骨架：

```
图片提示词：xxx.svg（标签 <fig:xxx>）

【整体描述】
[1-3 句：整体风格、背景、画布尺寸与方向、面板数量与排列方式]

【面板：XXX】（每个面板/层次一段，单面板图也用此段）
[自然语言段落，按空间或逻辑顺序描述本面板内全部可见元素：
 几何对象（圆/点/箭头/填充区域/坐标轴/网格）的位置、尺寸、
 线型、颜色、线宽；每个元素的标注文本与字体大小、颜色、
 相对位置。所有数值精确到小数点后 1-2 位。]

【配色与文字】
[一段或几段：汇总全图配色语义（"X 用蓝色 #xxx，Y 用红色 #yyy"）、
 字体风格（无衬线/衬线、是否斜体）、图内文字语言（统一英文）、
 是否显示坐标轴与网格等全局文字规则。]

【数学验证】
[自然语言段落，列出 2-5 项需验证的数学关系：每项一句话陈述
 "X = Y" 的检查与结论（"R = dist(z0, ±1) = 1，与图示一致"）。
 验证不通过的图不得进入提示词阶段。]
```

#### 标题行规范

第一行格式固定：`图片提示词：xxx.svg（标签 <fig:xxx>）`。文件名与标签名必须与大纲规划阶段登记的清单一致。

#### 段落顺序与省略规则

- 必有：【整体描述】、【面板：XXX】、【数学验证】
- 单面板图：【面板：XXX】只用一段；多面板图每个面板一段，段首重复 `【面板：XXX】` 标题
- 配色/文字可单列【配色与文字】段，也可直接融入各面板段落；融入时必须在第一段（整体描述）末尾点明全局配色基调
- 复杂图（3+ 面板或层次多）建议拆出独立的【配色与文字】段以便查阅

#### 段落内描述要求

每个几何元素在段落中按空间或逻辑顺序提及，必须覆盖：
- **类型与位置**：例如"圆心 (0,0)、半径 1.0 的虚线圆"、"位置 (1,0) 与 (-1,0) 的红色 × 标记"
- **视觉样式**：线型（实线/虚线/点线）、颜色（hex 或语义色名）、线宽（pt 数值）、填充色与透明度（alpha 数值）
- **标注**：标注文本（精确的 LaTeX/Unicode 字符串）、字体大小（pt 数值或"小/中/大"相对值）、字体颜色、相对位置（"标在圆右上方"、"置于点外侧"）

数值要求：所有坐标、半径、长度精确到小数点后 1-2 位（如 `R = 1.0`、`alpha = 0.3`），禁止"适当位置"、"约略"等模糊表述。

### 2.3 关键细节要求

提示词中**必须明确**以下细节（否则生成脚本的 AI 会自行猜测，结果不可控）：

#### 坐标与范围
- 坐标轴范围：`x ∈ [-2, 2]`, `y ∈ [-2, 2]`
- 等比例坐标轴（复平面图必须 `aspect='equal'`）
- 原点位置、轴标签（"Re z" / "Im z"，不是 "x" / "y"）

#### 几何元素
- **圆**：圆心坐标、半径、线型（实线/虚线/点线）、颜色、线宽
- **点**：坐标、大小、颜色、形状（实心圆/空心圆/×/●）
- **箭头**：起点、终点、弯曲程度（直线/弧线）、颜色
- **填充区域**：边界描述、填充颜色、透明度（alpha 值）
- **网格线**：是否显示、间距、颜色（通常浅灰 #eeeeee）

#### 文字标注
- 标注内容（精确的 LaTeX/Unicode 文本）
- 标注位置（相对于哪个元素，偏移方向和距离）
- 字体大小（相对大小：小/中/大，或具体 pt 值）
- 字体颜色

#### 多面板
- 面板数量与排列（水平/垂直/网格）
- 面板间距
- 每个面板的标题
- 面板是否共享坐标轴范围

### 2.4 数学准确性验证

编写提示词时**必须同步验证**数学关系：

- 收敛圆的半径是否等于到最近奇点的距离
- 映射后的曲线是否真的是原曲线的像（逐点验证 2-3 个点）
- 填充区域的边界是否与定理陈述一致
- 多面板中的相同对象在不同面板中是否保持一致

验证不通过的图不能进入提示词阶段——先修正数学，再画图。

## 3. 复分析常用图片类型

### 3.1 复平面几何图

用于：围道、收敛域、奇点分布、零点分布

关键要素：
- 等比例坐标轴（`aspect='equal'`）
- Re/Im 轴标签（不是 x/y）
- 虚线圆/实线圆区分边界
- 奇点用 × 标记，零点用 ● 标记
- 填充区域用半透明色

### 3.2 域映射双面板图

用于：保角映射、Möbius 变换、指数映射

关键要素：
- 左右面板：z-平面（定义域）+ w-平面（像）
- 中间映射箭头 "$w = f(z)$"
- 原像网格（等间距直线/圆）→ 像网格（变形后的曲线）
- 特征点标注（原像点 → 像点，用相同颜色对应）
- 边界曲线用粗线，内部网格用细线

### 3.3 函数模长/曲面图

用于：|f(z)| 的行为、最大模原理直观

关键要素：
- 3D 曲面或 2D 等高线（二者选一，3D 更直观但等高线更精确）
- 如果用 3D：视角角度要能看到峰值和零点
- 如果用等高线：标注等值线数值
- 关键特征点标注（极点处 → ∞，零点处 → 0）

### 3.4 多概念对比图

用于：三类奇点对比、多种收敛行为对比

关键要素：
- 多面板水平排列
- 每个面板标题明确
- 配色在各面板间保持一致
- 面板间留白分隔（不用实线）

### 3.5 围道变形图

用于：Cauchy 定理、变形不变性的证明

关键要素：
- 原始围道（实线）和变形后围道（虚线）
- 围道内的奇点用 × 标记
- 变形箭头表示连续形变过程
- 标注"同伦"或"变形不变"

## 4. 提示词质量检查

编写完提示词后，逐项检查：

- [ ] **数学自洽**：所有几何关系与定理/公式一致
- [ ] **元素完整**：每个可见元素都有描述（类型、位置、样式、标注）
- [ ] **坐标精确**：数值可计算，不含模糊描述（如"适当位置"→ 改为具体坐标）
- [ ] **配色一致**：同一语义在不同面板/图中使用相同颜色
- [ ] **标注语言**：图内标注用英文，与全书风格一致
- [ ] **无冗余**：图中每个元素都传递信息，没有纯装饰元素
- [ ] **尺寸合理**：选定的宽高比适合内容（复平面用正方形或 4:3，双面板用 16:9）

## 5. 实际示例

### 示例：`<fig:taylor-disk>` 收敛半径图

```
图片提示词：taylor-disk.svg（标签 <fig:taylor-disk>）

【整体描述】
数学教科书风格矢量插图，纯白色背景，简洁扁平风格，无外边框，
无大标题，16:9 横向画布，双面板水平排列，左右面板等宽共享
y 轴范围 [-2.0, 2.0]，面板间距约 1.0 单位。两面板分别展示
f(z) = 1/(1-z²) 在不同展开中心 z_0 的 Taylor 收敛圆盘，
奇点为 z = ±1。全图配色基调：收敛区域浅蓝、展开中心深蓝、
奇点红色，文字统一黑色无衬线。

【面板：左 — z_0 = 0 处的展开】
坐标轴为标准 Re/Im 轴，范围 x ∈ [-2.0, 2.0]、y ∈ [-2.0, 2.0]，
黑色 #333333 细线带箭头，轴标签 "Re z" 与 "Im z" 置于轴末端。
画面中央绘一个圆心 (0.0, 0.0)、半径 R = 1.0 的虚线圆，线型
虚线、颜色深灰 #555555、线宽 1.5pt；圆内填充浅蓝 #d4e6f1、
alpha = 0.3，圆内中央标黑色文本 "converges"。圆周右上方
标 "R = 1.0"（深灰 #555555，11pt）。展开中心为位置 (0.0, 0.0)
的实心圆，填充深蓝 #1a3a6b、半径 5pt，左下方标 "z_0 = 0"
（黑色 #333333，11pt）。两个奇点用红色 #c0392e 的 × 形标记，
位置 (1.0, 0.0) 与 (-1.0, 0.0)，线宽 2.0pt，无额外标注。
圆外右上角标黑色文本 "diverges"。

【面板：右 — z_0 = 1/2 处的展开】
坐标轴与左面板一致（同范围、同样式、同标签）。画面中央绘
一个圆心 (0.5, 0.0)、半径 R = 0.5 的虚线圆，线型虚线、颜色
深灰 #555555、线宽 1.5pt；圆内填充浅蓝 #d4e6f1、alpha = 0.3，
圆内中央标黑色文本 "converges"。圆周右上方标 "R = 0.5"
（深灰 #555555，11pt）。展开中心为位置 (0.5, 0.0) 的实心圆，
填充深蓝 #1a3a6b、半径 5pt，左下方标 "z_0 = 1/2"（黑色
#333333，11pt）。最近奇点用红色 #c0392e 的 × 形标记，位置
(1.0, 0.0)（恰在圆周上），线宽 3.0pt 加粗，上方标 "nearest"
（红色 #c0392e，10pt）。远奇点用灰色 #999999 的 × 形标记，
位置 (-1.0, 0.0)（圆外），线宽 1.5pt 淡化，无标注。

【配色与文字】
收敛区域填充统一浅蓝 #d4e6f1（alpha = 0.3）；收敛圆虚线统一
深灰 #555555（1.5pt）；展开中心统一深蓝 #1a3a6b 实心圆（5pt）；
最近奇点红色 #c0392e 加粗（3.0pt）；远奇点灰色 #999999 淡化
（1.5pt）；坐标轴与全部文字黑色 #333333，字体无衬线，数学
符号斜体。图内文字统一英文。坐标轴显示，无网格线。

【数学验证】
左面板收敛半径 R = min(|0 - 1|, |0 - (-1)|) = min(1, 1) = 1.0，
与图示 R = 1.0 一致。右面板收敛半径 R = min(|1/2 - 1|,
|1/2 - (-1)|) = min(0.5, 1.5) = 0.5，与图示 R = 0.5 一致。
右面板收敛圆经过原点：|1/2 - 0| = 0.5 = R，与图示圆周过 (0,0)
一致。右面板收敛圆与 z = 1 相切：|1/2 - 1| = 0.5 = R，与图示
奇点 (1,0) 落在圆周上一致。
```
