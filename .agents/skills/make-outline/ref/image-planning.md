# 图片规划与绘图脚本编写指南

本文件指导在大纲规划阶段如何判断图片必要性，以及如何编写生成 SVG 的 Python/Matplotlib 绘图脚本。

---

## 1. 图片必要性判断

### 1.1 核心原则：图片必须传递文字无法高效传递的信息

数学笔记中的图片不是装饰，而是**证明或理解的必要辅助**。判断标准：

> **如果去掉这张图，读者是否需要花更多时间从文字/公式中重建几何直觉？如果是，图有必要；如果文字已经足够清晰，图就是凑数。**

### 1.2 三级判断

| 级别 | 判断 | 标准 | 处理 |
|------|------|------|------|
| **A. 必须有** | 几何构造是证明/概念的核心 | 去掉图后读者无法理解论证 | 规划并编写绘图脚本 |
| **B. 建议有** | 图能显著加速理解，但文字也能说清 | 多概念对比、复杂域映射 | 规划但可降级为简版 |
| **C. 不需要** | 公式本身已自明，或图只是文字的重述 | 简单函数图、单一定义的示意 | **不画图** |

> 后文"脚本"均指 matplotlib 绘图脚本；"图片名"与规划清单及 `<fig:xxx>` 标签一致。

### 1.3 具体判断清单

**A 级（必须有图）**：
- 证明中用到的几何构造（如围道变形、圆环内的积分路径）
- 复平面上的域映射（z-平面 → w-平面，因为映射后的形状无法从公式直觉得到）
- 多值函数的分支结构（branch cut、Riemann 曲面）
- 需要视觉对比的多个对象（如三类奇点的 Laurent 展开对比）
- 收敛区域的几何刻画（如收敛半径 = 到最近奇点的距离）

**B 级（建议有图）**：
- 函数模长的曲面/等高线（如 |sin z| 的周期结构）
- 映射前后的网格变形（保角映射的直观）
- 多个相关概念的并排对比（如三种收敛行为）

**C 级（不画图）**：
- 简单定义的文字叙述已经足够（如"开圆盘"的定义 — 读者知道圆盘长什么样）
- 公式本身已经自明的函数图像（如 $e^x$ 的曲线 — 不需要图来理解指数增长）
- 仅标注一个点或一条线的"示意图"（信息量太低）
- 纯代数推导中无几何含义的中间步骤
- 与前后章节已有图片高度重复的内容

### 1.4 数量控制

- 每章 **1-3 张图** 是正常范围
- 超过 4 张需要审视：是否有 C 级图可以删除？
- 一节内最多 1 张图；如果某节需要 2 张以上，考虑合并为多面板

## 2. 绘图脚本编写规范

### 2.1 工作流

图片由本仓库内的 **Python/Matplotlib 脚本**直接生成，不再经过"提示词 → 外部生成"中转：

1. **脚本位置**：对应主题目录下的 `scripts/<图片名>.py`，一图一脚本，文件名与规划清单及 `<fig:xxx>` 标签一致
2. **输出位置**：脚本将 SVG 写到主题目录的 `img/<图片名>.svg`（用 `Path(__file__).resolve().parent.parent / "img"` 定位，输出前确保目录存在）
3. **运行方式**：在仓库根目录执行 `uv run "<subject>/scripts/<图片名>.py"`（依赖由仓库根 `pyproject.toml` 统一管理，已含 matplotlib/numpy）
4. **人工核验**：生成 PNG 预览检查无重叠、无越界、标注可读，再替换 `0.Wiki/null.svg` 占位文件
5. **提交约定**：`img/` 已被 .gitignore 忽略，提交只含脚本与 `.typ`；`scripts/` 目录需要提交

### 2.2 脚本结构模板

```python
"""<一句话用途>.  Generates img/<图片名>.svg (面板说明).  Run from the repository root:  uv run ..."""
from pathlib import Path
import matplotlib.pyplot as plt
import numpy as np

BLUE, RED, GRAY = "#3b6fb6", "#c74440", "#888888"   # 统一语义色
OUT = Path(__file__).resolve().parent.parent / "img" / "<图片名>.svg"

def main():
    fig, axes = plt.subplots(...)   # 面板布局
    # ... 每个面板一段：几何对象 → 标注 → 标题
    fig.tight_layout()
    OUT.parent.mkdir(parents=True, exist_ok=True)
    fig.savefig(OUT, format="svg", bbox_inches="tight")

if __name__ == "__main__":
    main()
```

### 2.3 关键细节要求

脚本中**必须明确**以下细节（数值精确，禁止"适当位置"式布局）：

#### 坐标与范围
- 坐标轴范围显式设定（如 `ax.set_xlim(-2.6, 2.6)`）
- 几何图必须 `ax.set_aspect("equal")`
- 原点位置、轴标签按数学惯例（复平面用 "Re z" / "Im z"）

#### 几何元素
- **圆/球**：圆心、半径、线型、颜色、线宽（线框球用外圆 + 赤道椭圆 + 子午椭圆）
- **点**：坐标、大小、颜色、形状（实心圆/×/●）
- **箭头**：起点、终点、颜色（`arrowprops=dict(arrowstyle=...)`）
- **填充区域**：顶点坐标、颜色、alpha（通常 0.08–0.3）

#### 文字标注
- 标注用 mathtext（`r"$\varphi$"` 等）；**注意 mathtext 不支持 `\bigl`/`\bigr`**，用 `\left(\right)` 代替
- `ax.annotate` 带箭头的引出标注，文字位置与箭头终点都显式给出
- 图内文字统一英文，与笔记正文一致；**正文与标注不得出现中文**

#### 多面板
- 面板数量与排列（`plt.subplots(1, N, figsize=...)`）
- 每个面板标题 `(a) ...` / `(b) ...`
- 同一语义对象在各面板中颜色一致

### 2.4 数学准确性验证

写脚本时**必须同步验证**数学关系：

- 收敛圆的半径是否等于到最近奇点的距离
- 映射后的曲线是否真的是原曲线的像（逐点验证 2-3 个点）
- 填充区域的边界是否与定理陈述一致（如特征带的斜率 = 波速）
- 多面板中的相同对象在不同面板中是否保持一致

验证不通过的图不能进入绘图阶段——先修正数学，再画图。

## 3. 复分析常用图片类型

### 3.1 复平面几何图

用于：围道、收敛域、奇点分布、零点分布

关键要素：
- 等比例坐标轴（`aspect='equal'`）
- Re/Im 轴标签（不是 x/y）
- 虚线圆/实线圆区分边界
- 奇点用 × 标记，零点用 ● 标记
- 填充区域用半透明色

### 3.2 域映射双面板图

用于：保角映射、Möbius 变换、指数映射

关键要素：
- 左右面板：z-平面（定义域）+ w-平面（像）
- 中间映射箭头 "$w = f(z)$"
- 原像网格（等间距直线/圆）→ 像网格（变形后的曲线）
- 特征点标注（原像点 → 像点，用相同颜色对应）
- 边界曲线用粗线，内部网格用细线

### 3.3 函数模长/曲面图

用于：|f(z)| 的行为、最大模原理直观

关键要素：
- 3D 曲面或 2D 等高线（二者选一，3D 更直观但等高线更精确）
- 如果用 3D：视角角度要能看到峰值和零点
- 如果用等高线：标注等值线数值
- 关键特征点标注（极点处 → ∞，零点处 → 0）

### 3.4 多概念对比图

用于：三类奇点对比、多种收敛行为对比

关键要素：
- 多面板水平排列
- 每个面板标题明确
- 配色在各面板间保持一致
- 面板间留白分隔（不用实线）

### 3.5 围道变形图

用于：Cauchy 定理、变形不变性的证明

关键要素：
- 原始围道（实线）和变形后围道（虚线）
- 围道内的奇点用 × 标记
- 变形箭头表示连续形变过程
- 标注"同伦"或"变形不变"

## 4. PNG 预览质量检查

运行脚本后，先转出 PNG 预览（临时文件即可，不提交），逐项检查通过后才替换占位文件：

- [ ] **数学自洽**：图中几何关系与定理/公式一致（见 §2.4 数学准确性验证）
- [ ] **无重叠**：标注文字、箭头、数据元素互不遮挡，与轴标签无碰撞
- [ ] **无越界**：所有曲线与标注都在坐标范围内（注意 ylim 裁掉负半支等隐性问题）
- [ ] **坐标精确**：无模糊布局，元素位置由脚本中显式数值确定
- [ ] **配色一致**：同一语义在不同面板/图中使用相同颜色
- [ ] **标注语言**：图内标注用英文，与全书风格一致，不得出现中文
- [ ] **无冗余**：图中每个元素都传递信息，没有纯装饰元素
- [ ] **尺寸合理**：面板布局适合内容（几何图用 equal aspect，双面板横向排列）

发现问题回到脚本修改后重新运行，不要手工修图。
