# 章节大纲规划技能

## 1. 何时使用

当用户要求"规划/规划一下这一章怎么写"或"做一个详细的大纲"时激活。本技能在写作**之前**运行，产出一份结构化大纲供用户确认，确认后再进入写入阶段。

## 2. 前置收集（并行执行）

在规划前，必须先收集以下信息：

### 2.1 全书章节结构
- Grep `initial.typ` 中所有 `^(=|==)` 标题行，获取章节骨架
- 确认当前章节在全书中的位置、前后章节的标题
- 识别可交叉引用的目标标签（已写章节中的 `<def:>` `<thm:>` `<eq:>` 等）

### 2.2 参考资料扫描
- 如果存在对应的 `chapters/chapXX.tex`，通读其内容，提取知识点清单和定义/定理顺序
- 标注用户特别强调的参考位置（如"参考 chap02.tex L104-115"）
- 参考资料仅作**补充**，大纲以自己的思路为主线

### 2.3 已有标签盘点
- Grep `^\] <[a-z]+:` 和 `^\$ <[a-z]+:` 获取已有标签列表
- 避免标签命名冲突；识别可复用的已有定义/定理标签

## 3. 大纲产出要素

大纲必须包含以下 6 个维度：

### 3.1 结构方案
- 列出 section（`==`）和 subsection（`===`）的标题（含中文翻译）
- 如需新增 section 或调整顺序，说明理由
- 每节的预估行数范围

### 3.2 知识点与组件规划
每个 section 用表格列出：

| 内容 | 组件/标签 | 备注 |
|------|-----------|------|
| 知识点描述 | `#definition` `<def:xxx>` | 定义/定理/性质/例/注等 |

组件选择遵循 `typst-writing-conventions` SKILL.md §9 的组件选择指南。

### 3.3 逻辑链路图
用 ASCII/文字流程图展示知识点间的依赖关系：
```
前置章节 → §X.1 概念A → §X.2 概念B（依赖A）→ ... → 远期兑现
```

标注三类链路：
- **向上**：依赖前置章节的哪些定义/定理（标明标签名）
- **横向**：本章各节之间的依赖
- **向下**：哪些远期章节会兑现本章埋的伏笔

### 3.4 标签系统设计
- 列出本章所有 `<def:>` `<thm:>` `<eq:>` `<fig:>` `<prop:>` `<ex:>` 标签
- 确认命名与已有标签风格一致
- 标注哪些标签会被后续章节交叉引用

### 3.5 图片规划
按 `typst-writing-conventions` SKILL.md §5 的图片工作流：
- 列出本章需要的图片（标签名、内容描述、布局建议、image_size、优先级）
- 标注哪些是核心图、哪些可选
- 规划完成后，写作时用 `0.Wiki/null.png` 占位

### 3.6 参考资料对照
如有 `chapXX.tex` 参考文件：
- 列出与参考资料的知识点对应关系
- 标注差异点（如"chap02 用公理式定义，我改为幂级数定义，理由..."）
- 确认用户强调的参考位置是否已落实

## 4. 交互流程

```
Step 1: 前置收集（并行 Grep/Read）
  ↓
Step 2: 产出大纲（上述 6 要素）
  ↓
Step 3: 对关键决策点用 AskUserQuestion 征求用户意见
  - 结构选择（如"单独成节 vs 并入"）
  - 图片数量与范围
  - 定义路径选择（如"幂级数定义 vs Euler 公式定义"）
  ↓
Step 4: 用户确认后进入写入阶段
```

### 4.1 决策点规则
- 只对**真正影响结构且用户可能有偏好**的决策提问
- 每个问题给 2-3 个选项，标注推荐项（`(Recommended)`）
- 不超过 3 个问题
- 不对细节（如标签名、具体措辞）提问——这些自己决定

## 5. 规范检查清单

大纲产出后自检：

- [ ] 所有 section 标题含中文翻译（`== Title // 中文`）
- [ ] 组件选择符合 SRP 原则（不重复其他章节已有定义）
- [ ] 标签命名前缀正确（`def:` `thm:` `eq:` `fig:` `prop:` `ex:`）
- [ ] 交叉引用的标签名与已有标签匹配（用 Grep 验证）
- [ ] 图片规划含标签名、布局建议、优先级
- [ ] 参考资料的差异点已标注
- [ ] 逻辑链路图标注了向上/横向/向下三类链路

## 6. 大纲输出格式模板

```markdown
# 第X章「标题」写作大纲

## 一、结构方案
（section 列表 + 新增/调整说明）

## 二、各节知识点、组件与标签
### §X.1 标题
| 内容 | 组件/标签 |
|---|---|
| ... | `#definition` `<def:xxx>` |

## 三、逻辑链路图
（ASCII 流程图）

## 四、图片规划
| # | 标签 | 内容 | 布局 | 优先级 |
|---|---|---|---|---|

## 五、参考资料对照
（与 chapXX.tex 的对应与差异）

## 六、需确认的决策点
（AskUserQuestion 的内容）
```

## 7. 写作阶段衔接

大纲确认后，进入写入阶段时：
1. 按 `typst-writing-conventions` SKILL.md 的所有规范执行
2. 按节顺序写入（每节一个 Edit），避免一次性写入全部内容
3. 每节写完后立即检查 Typst 语法陷阱（多字母变量、括号、标签位置等）
4. 图片用 `0.Wiki/null.png` 占位（复制到 `img/` 改名为实际图片名）
5. 全部写完后编译验证
6. 最后汇总输出所有图片的提示词（按 `illustration-prompt` 技能规范）
