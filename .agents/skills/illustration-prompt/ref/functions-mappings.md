# 函数 / 映射图模板（Functions & Mappings）

涵盖四类：普通实函数曲线、多元实函数（曲面 + 等高线）、复函数双平面映射、一般映射示意。

## 0. 通用注意事项（AI 生图可靠性）

AI 文生图对**精确数学内容不可靠**，编写提示词与验收时必须注意：

- **文字标注风险**：公式、下标（如 `z1`、`f(D)`）可能拼错或渲染成乱码
  - 标注尽量少而短：优先 `f(x)`、`w = f(z)` 这类简单表达式，避免复杂公式上墙
  - 下标用数字形式（`z1`、`z2`），不用 Unicode 下标（`z₁`）
  - 提示词末尾明确"所有文字拼写准确"
- **形状风险**：曲线/区域是"示意"而非精确绘制，提示词应描述拓扑特征（如"闭合曲线围绕极值点"）而非苛求精确坐标
- **验收与退回**：生成后必须检查图片；效果差则退回方案——删除图片改纯文字描述，或改用代码绘图（如 Typst 原生 / Python 导出）
- **异步轮询**：文生图 API 首次请求可能返回"生成中"占位图（固定字节数），需间隔轮询同一 URL，直至下载内容字节数变化

## 模板 A：普通实函数 y = f(x)

**适用**：单变量实函数曲线；函数性质展示（单调性、极值、渐近线、凹凸性）

**布局**：单面板曲线图；需配几何示意（切线、割线、曲边梯形面积）时用左右两面板（左 = 几何示意，右 = 曲线）。

**提示词骨架**：

```
【整体描述】
数学教科书风格矢量插图，纯白色背景，细黑色线条，无外边框，无大标题。

【面板1：函数曲线】
标准直角坐标系：水平轴标 "x"，垂直轴标 "y"，原点标 "O"，浅灰色细网格。
蓝色光滑曲线表示函数，曲线附近粗体标注表达式 "y = f(x)"。
[按需] 垂直/水平渐近线用红色虚线并标注方程；
[按需] 极值点、拐点用黑色实心圆点，旁边标注坐标 (a, f(a))；
[按需] 关键刻度（如渐近值、截距）标在坐标轴上；
[按需] 单调增/减区间可用箭头或浅色底纹区分。
面板上方居中小标题 "y = f(x)"。
```

**验证项**：

- 特征点：至少 2-3 个点函数值计算正确
- 渐近行为：$x \to \pm\infty$ 及奇点两侧的行为与曲线走势一致
- 定义域：有间断点/垂直渐近线时，提示词必须明确画出断开
- 数值范围：选取能展示完整特征的自变量区间（见主文件 §3）

## 模板 B：多元实函数 z = f(x, y)

**适用**：二元函数曲面、等高线、梯度场、切平面等

**布局**：左右两面板：左 = 3D 曲面图（z 轴竖直向上），右 = 等高线俯视图（xy 平面）。**等高线必须是曲面向 xy 平面的投影，两者必须一致**。

**提示词骨架**：

```
【整体描述】
数学教科书风格矢量插图，纯白色背景，无外边框，无大标题，左右两面板留白分隔。

【面板1：曲面图】
3D 直角坐标系：三轴分别标注 "x" "y" "z"，浅灰色网格线。
浅蓝色半透明光滑曲面表示 z = f(x, y)，曲面上方粗体标注 "z = f(x, y)"。
[按需] 极大/极小值点用黑色实心点标注；
[按需] 鞍点等临界点明确画出。
面板上方居中小标题 "Surface z = f(x, y)"。

【面板2：等高线图】
2D 直角坐标系 xOy，浅灰网格。
若干条蓝色光滑等高线（[按需：闭合曲线围绕极值点投影]），
[按需] 每条等高线旁标注对应高度值；
[按需] 用小箭头表示梯度方向（垂直于等高线、指向上升方向）。
面板上方居中小标题 "Level curves"。
```

**验证项**：

- 临界点：位置与个数在两面板中一一对应
- 等高线疏密与坡度一致：陡处密、缓处疏
- 凹凸一致：极小值 → 闭合环状等高线；鞍点 → 交叉双曲线族

## 模板 C：复函数双平面映射 w = f(z)

**适用**：复函数的几何解释——z-平面（定义域）到 w-平面（像）的变换示意；区域映射、保角映射示例

**布局**：左右两面板 + 中间映射箭头。左 = z-平面（定义域 $D$ 与标记点），右 = w-平面（像区域 $f(D)$ 与像点），中间一条粗红色弯曲箭头标 $w = f(z)$。

**提示词骨架（实战范例：一般映射）**：

```
数学教科书风格的矢量插图，纯白色背景，简洁扁平风格，细黑色线条，
横向布局分为左右两个面板，面板之间留有明显空白，无外边框，无大标题。

【左面板：z-平面】
一个标准二维直角坐标系：水平轴为黑色细线带箭头，右端标注英文 "Re z"，
垂直轴黑色细线带箭头，上端标注 "Im z"，两轴交点标 "O"，平面内浅灰色细网格线。
中部一个浅蓝色半透明填充的光滑区域 D（形状按需求选：圆盘/扇形/带形），
蓝色细实线边缘，区域内标黑色文本 "D"。
区域内均匀放置 2-3 个黑色实心小圆点，旁标 "z1"、"z2"、"z3"。
面板上方居中小标题 "z-plane"。

【右面板：w-平面】
同样大小的直角坐标系：水平轴右端标 "Re w"，垂直轴上端标 "Im w"，原点标 "O"，
同样浅灰网格。中部一个浅蓝色半透明填充的变形区域，
[关键] 像区域形状必须与映射 f 的实际作用一致（见下方对照表），
蓝色细实线边缘，区域内标 "f(D)"。
区域内与左侧点位对应的黑色实心小圆点，分别标 "w1"、"w2"、"w3"。
面板上方居中小标题 "w-plane"。

【中间映射箭头】
两个面板之间一条粗的红色弯曲箭头，从左侧区域指向右侧区域，
箭头上方标黑色文本 "w = f(z)"。

配色：坐标轴与文字黑色，区域浅蓝色半透明，映射箭头红色，网格浅灰色。
所有文字为无衬线英文，拼写准确，不出现任何中文。
```

**像区域形状对照表**（提示词中"变形区域"的描述依据）：

| 映射 | 像区域特征 | 提示词描述要点 |
|------|-----------|---------------|
| $w = \overline{z}$ | 关于实轴镜像 | "与左侧区域关于水平轴上下翻转对称" |
| $w = z^2$ | 张角加倍（如上半平面 → 全平面挖正实轴） | "区域角度范围扩大为两倍，呈张开状" |
| $w = e^z$ | 带形 → 圆环 | "矩形带状区域变为同心圆环带" |
| $w = az + b$ | 相似形状（旋转+缩放+平移） | "形状不变，整体放大/旋转/平移" |
| 一般 $f$ | 拓扑保持的平滑变形 | "与左图形状不同、经平滑拉伸变形的不规则区域" |

**验证项**：

- 点对应：逐点验证 $w_i = f(z_i)$（如 $f(z)=z^2$ 时 $1+i \mapsto 2i$）
- 像区域形状与映射作用一致（查上方对照表）
- **多值函数**（根式、对数、反三角）：只画单值分支，并要求正文中注明分支切法
- 保角映射强调时：可在两面板各画一对相交曲线，要求交角相同

## 模板 D：一般映射 T: X → Y

**适用**：线性变换、坐标系变换、抽象集合间的映射（单射/满射/双射示意）

**布局**：左右两面板 + 中间映射箭头（与模板 C 同构，坐标轴标签换成对应空间的记号）。

**按映射类型差异**：

| 类型 | 左面板 | 右面板 | 箭头与标注 |
|------|--------|--------|-----------|
| 集合间映射 | 不规则闭合曲线围成集合 X，内部若干点 | 集合 Y 及对应点 | 逐点弯曲细箭头连接；单射不汇聚、满射每点被指、双射一一对应；上方标 "T" 或 "X -> Y" |
| 线性变换 $y = Ax$ | 平面网格 + 基向量 $e_1, e_2$（蓝色/红色粗箭头） | 变换后网格（平行四边形化）+ 像 $Ae_1, Ae_2$ | 上方标 "y = Ax"；[按需] 用浅色阴影标单位正方形变形后的面积（行列式） |
| 坐标变换 | 原坐标系 $(x, y)$ 中的等值线/区域 | 新坐标系 $(u, v)$ 中的对应图形 | 上方标变换方程组 |

**验证项**：

- 映射性质（单射/满射/双射）与图形中箭头的汇聚/覆盖关系一致
- 变换类型正确体现：旋转→角度保持、剪切→平行线保持、投影→维度降低
- 线性变换：基向量的像与矩阵列向量一致
