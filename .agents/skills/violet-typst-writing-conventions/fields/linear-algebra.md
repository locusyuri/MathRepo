# 矩阵对象（linear-algebra.md）

写任何涉及**矩阵、行列式、向量空间、范数、内积、张量、伴随**的公式时加载本文件。

与 relations/arrows 等家族不同，本文件是**对象级构造**：`mat()`、`"det"(A)` 是多字符语法，不是单个符号映射。下标/多字母/分数等通用规则见 [general.md](general.md)。

## 1. `mat()` 矩阵写法

Typst 使用 `mat()` 函数写矩阵。**行之间用分号 `;` 分隔，行内元素用逗号 `,` 分隔。**

```typst
// 2×2 矩阵（单行紧凑写法）
$mat(a, b; c, d)$

// n×n 矩阵（多行写法，每行以分号结尾）
$mat(
  a_(11), a_(12), ..., a_(1n);
  a_(21), a_(22), ..., a_(2n);
  dots.v, dots.v, dots.down, dots.v;
  a_(n 1), a_(n 2), ..., a_(n n);
)

// 单行矩阵（不加多余括号）
$mat(a_1, a_2, ..., a_n)$

// 分块矩阵（mat 可以作为分块元素）
$mat(I_r, O; O, O)$
$mat(A, B; C, D)$
```

**规则**：
- 行间分隔用 `;`，行内元素用 `,`——**不要给行加多余括号**：`mat((a, b), (c, d))` 是错误的
- 省略号行用 `dots.v, dots.v, dots.down, dots.v` 保证对齐
- `mat()` 可以嵌套作为分块矩阵的元素
- 行末必须有 `;`（包括最后一行，除非是单行矩阵）

### 1.1 分隔符环境映射（LaTeX → mat）

| LaTeX 环境 | 分隔符 | Typst |
|-----------|--------|-------|
| `pmatrix` | `()` | `mat(delim: "(", ...)` |
| `bmatrix` | `[]` | `mat(delim: "[", ...)` |
| `Bmatrix` | `{}` | `mat(delim: "{", ...)` |
| `vmatrix` | `\|\|` | `mat(delim: "\|", ...)`（行列式，见 §2） |
| `Vmatrix` | `\|\|` | `mat(delim: "\|\|", ...)`（范数） |
| `matrix` / `array` | 无 | `mat(...)` |

行分隔 `\\` → `;`，列分隔 `&` → `,`。

### 1.2 用通项表示矩阵：`(a_(i j))_(m times n)`

用**通项数组**表示一个矩阵时，**必须加尺寸下标** —— `(a_(i j))_(m times n)`，不要写裸的 `(a_(i j))`（这是全库重点，用户已设定稿）：

```typst
// 正确 — 通项 + 尺寸下标
$A = (a_(i j))_(m times n)$
$A^"T" = (a_(j i))_(n times m)$     // 转置通项，n×m
$A B = (c_(i j))_(m times p)$

// 错误 — 通项数组不带尺寸
$A = (a_(i j))$
```

**通项下标记法**：下标里多个字符用空格分隔、**不加引号**：`a_(i j)`、`a_(k j)`、`a_(n 1)`、`a_(k k)`；纯数字下标保持一个 token（`a_(11)`）。**转置用正体 `^"T"`，不是 `^T`。**

规则：
- 通项矩阵记号一律 `(通项)_(行数 times 列数)`，尺寸下标写成 `(m times n)` 括起来
- 只有用 `mat(...)` 把矩阵**展开**写出时才不写尺寸下标（见 §1）
- 对角/三角/对称等特殊矩阵若为 $n times n$，通项写 `(a_(i j))_(n times n)`

## 2. 行列式写法

行列式有两种场景，分别使用不同的 Typst 写法。**绝对不要用 `abs()` 或 `|...|` 表示行列式。**

| 场景 | 写法 | 示例 |
|------|------|------|
| 符号矩阵的行列式 | `"det"(A)` | $"det"(A) = 0$ |
| 显式矩阵的行列式 | `mat(delim: "\|", ...)` | $mat(delim: "\|", a, b; c, d)$ |

```typst
// 符号矩阵行列式（A 是变量名）
$"det"(A) != 0$
$"det"(A B) = "det"(A) "det"(B)$
$f(lambda) = "det"(lambda E - A)$

// 显式矩阵行列式（Vandermonde，竖线自动缩放）
$mat(
  delim: "\|",
  1, 1, 1, dots, 1;
  x_1, x_2, x_3, dots, x_n;
  x_1^2, x_2^2, x_3^2, dots, x_n^2;
)
```

**规则**：
- `"det"(A)` 用于符号矩阵（A 是变量名），不是 `abs(A)` 或 `|A|`
- 显式矩阵的行列式用 `mat(delim: "|", ...)` 让竖线自动缩放，不是 `abs(mat(...))`
- `abs()` 仅用于真正的绝对值（标量、复数模、内积模），**不是**行列式（见 general.md §7）
- T**ypst 行列式的符号就是 `mat(delim: "|", ...)` 形式**，不是 `|A|`，也不是 LaTeX 的 `\det A` 单独竖线

## 3. 范数写法

双竖线范数用 `||...||`（裸双竖线，不用 `lVert`/`rVert`），不是绝对值也不是行列式：

```typst
// 范数（双竖线）
$||alpha||$
$||alpha - "proj"_(W)(alpha)||^2$

// 柯西-施瓦茨（内积模用 abs）
$abs((alpha, beta)) <= ||alpha|| ||beta||$
```

规则：
- `||...||` 用于范数（如 $||alpha||$），不是绝对值也不是行列式
- 范数统一用裸双竖线 `|| ... ||`，不用 `lVert` / `rVert`

## 4. 内积、伴随、正交、直和/张量

| Unicode / LaTeX | Typst | 含义 |
|-------|-------|------|
| `(·, ·)` | `(dot, dot)` | 内积占位（点用 `dot`） |
| `†` | `†`（可直接用） | 伴随矩阵/共轭转置 $A^†$ |
| `⊥` | `⊥`（可直接用） | 正交/正交补 $W^⊥$、$alpha ⊥ beta$ |
| `⊕` | `⊕`（可直接用）或 `plus.o` | 直和 $V_1 ⊕ V_2$ |
| `⊗` | `otimes` | 张量积 |
| `×` | `times`（见 general.md） | 数集/维数乘积 |

```typst
// 内积
$(alpha, beta)$        // 或占位 $(dot, dot)$

// 伴随矩阵
$A^†$
$A^† A$

// 正交补
$W^⊥$

// 直和
$V_1 ⊕ V_2$

// 张量积
$U otimes W$
```

## 5. 规则要点（自查清单）

1. **矩阵**：`mat()` 展开（行间 `;`、行内 `,`、行末 `;`、不加多余括号）；用**通项**表示时加尺寸下标 `(a_(i j))_(m times n)`（见 §1.2）。
2. **行列式**：符号矩阵 `"det"(A)`，显式矩阵 `mat(delim: "\|", ...)`；**禁止 `abs()` / `|A|`**。
3. **范数**：`||...||`（裸双竖线），不是绝对值也不是行列式。
4. **内积模**：`abs((alpha, beta))`。
5. **伴随/共轭转置**：`†`；**正交**：`⊥` 可直接用 Unicode。
6. **下标**：通项下标多字符用空格分开不加引号（`a_(i j)`），转置用正体 `^"T"`。
